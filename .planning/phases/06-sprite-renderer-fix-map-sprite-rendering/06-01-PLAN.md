<objective>
**Fix the Sprite Color Channel Swap in SpritesFile.ts**

**Purpose:** The .spr file stores pixel data in RGB byte order, but `decodeSprite()` reads pixels as B,G,R. This causes a red-blue channel swap, making all sprites appear with a blue tint. Fix the byte read order to R,G,B — matching both the .spr format and the already-correct background color read (lines 39-41).

**Output:** One-line variable binding change in `SpritesFile.ts:decodeSprite()` lines 64-66. No other files modified.

**Note on RENDER-03 direction:** RENDER-03 requires "correct colors and direction". This plan fixes colors (via channel swap fix). Direction mapping for creature outfits (North/West potential collision at px=0 in `drawOutfit()`) is NOT addressed per D-02 scope boundary — requires separate investigation if creatures face wrong directions post-fix.
</objective>
